# 오렌지 껍질 실험실

중학교 1학년 구의 겉넓이 수업을 위한 정적 웹앱. 원의 수를 예상하고 오렌지를 돌려 껍질을 벗긴 뒤, 같은 지름인 원에 옮겨 비교한다. 학생이 관찰 결과와 근거를 적은 후 공식을 정리한다.

## 실행

- `dist/index.html`을 Chrome 또는 Edge에서 연다. 외부 설치·로그인·네트워크 연결 없이 실행한다.
- Node.js가 있으면 이 폴더에서 `node serve.cjs` 실행 후 `http://127.0.0.1:4180` 접속.
- 수업용 주소: https://tpwjdo3o-math.github.io/orange-surface-lab/
- 저장소: https://github.com/tpwjdo3o-math/orange-surface-lab
- 정적 호스팅 대상은 `dist/` 전체. 사용자 승인에 따라 GitHub Actions로 검사 후 GitHub Pages에 배포한다. `main` 브랜치에 변경을 푸시하면 자동 반영된다.

## 활동

1. 화면 위에서 원의 수를 예상하고 시작한다(이유 작성은 선택). 원은 1~8개로 조절할 수 있다. ‘벗기고 채우기’, ‘껍질 벗기기’, ‘한 조각/한 줄 벗기기’를 먼저 눌러도 현재 원의 수를 예상으로 기록하며 시작한다.
2. 드래그로 오렌지를 회전하거나 껍질을 바깥으로 당겨 벗긴다. ‘한 조각 벗기기’, ‘한 줄 벗기기’로 대체 조작 가능.
3. 벗긴 껍질을 원에 끌어 놓거나, 원을 선택하고 버튼으로 옮긴다. ‘차례로 옮기기’는 이미 벗긴 껍질만 빈 공간에 옮긴다.
4. 원의 개수를 바꾸어 남는 껍질과 빈 공간을 비교한다. 채운 원을 삭제하면 그 안의 조각은 보관함으로 돌아간다.
5. 남거나 부족한 부분이 없는 상태에서 결과를 정리한다. 다른 크기로 재실험할 수 있다.
6. 발견한 개수와 자기 설명을 작성한 후 `4πr²`로 정리하고, 반지름이 2배인 경우에 적용한다.

반지름 2~5 cm. 껍질을 벗기기 시작한 뒤에는 크기를 잠가 실험 조건을 유지한다. 크기 변경은 재실험에서 한다. 예상·설명은 메모리에만 있으며 초기화·새로고침·탭 닫기 시 사라진다. 탐구 기록 저장 기능은 텍스트 파일을 내려받는다. 개인정보나 입력 내용을 서버로 전송하지 않는다.

## 모형과 정확성

두께가 없는 껍질을 가진 완전한 구를 가정한다. 높이가 같은 6개 띠와 8개 경도 구간으로 48개의 같은 넓이 조각을 만든다. 구면에서 무차원 높이를 z, 경도를 λ라 하면 면적 요소는 `r² dλ dz`이다. 한 조각의 넓이는 `r² × (2/6) × (2π/8) = πr²/12`. 원에서는 같은 넓이의 작은 곡선 조각 48개 중 4개로 나누어 표시한다. 무차원 넓이 좌표 q=(ρ/r)²와 각도 a에 대해 a를 a+f(q)로 바꾸는 변환으로 넓이를 보존하며 조각의 경계를 굽힌다. 곡선 경계는 렌더링 시 작은 선분으로 근사한다. 따라서 조각 이동·원의 추가 및 삭제에서 넓이가 보존된다.

원 안의 곡선 조각은 곡면 껍질의 실제 전개도가 아니다. 껍질을 아주 작게 나누어 넓이를 보존하며 정돈한 표현이다. 이 모형은 수학적으로 알려진 넓이 관계에 따라 구성한 체험 도구이며 독립적인 실험적 증명은 아니다. 실제 과일의 모양·두께·틈·겹침에 따른 측정 오차는 재현하지 않는다. 이런 가정은 앱 내 ‘이 실험의 약속과 수업 안내’에도 제공한다.

오렌지의 구면 투영과 비교 원은 같은 화면 배율을 사용한다. 반응형 화면에서는 두 그림의 크기를 함께 조정한다. 오렌지는 정사영과 음영·표면 질감으로 입체를 표현하며 원근 투영이 아니다.

## 파일

- `dist/index.html`: 활동과 수업 안내, 제작자 표시
- `dist/style.css`: 반응형 화면과 접근성 스타일
- `dist/app.js`: 구면 렌더링, Pointer Events, 탐구 상태와 기록
- `dist/math.js`: 면적과 조각 분할 계산
- `math.test.cjs`: 독립 수치 적분과 넓이 보존 검산
- `serve.cjs`: 로컬 정적 미리보기 서버
- `curriculum-reference.md`: 교육과정 근거와 활동 설계
- `verification.md`: 수행한 검증과 한계
- `AGENTS.md`: 프로젝트 개발 지침

검사: `node --check dist/app.js`, `node --check dist/math.js`, `node math.test.cjs`.

외부 이미지·폰트·라이브러리를 사용하지 않았다. 교육과정·교과서 PDF는 재배포 조건을 확인하지 못해 복사하지 않았으며 출처와 참조 위치만 기록했다. 공개 파일에는 학생 입력이나 인증 정보를 포함하지 않는다.
